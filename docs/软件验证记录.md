## 固件编译与分区

使用本机 Keil µVision 5 / ARM Compiler 6.7，完成四目标全量编译；此后修改的源文件完成最终增量编译。四个目标最终均为 **0 Error(s), 0 Warning(s)**。日志保存在 `build/<目标名>.log`，链接布局见 `MDK-ARM/<目标名>/<目标名>.map`。

| 目标 | Flash 基地址 | 最终 BIN 字节数 | 分区字节数 | 链接统计 RAM：RW + ZI |
|---|---:|---:|---:|---:|
| Cabinet_Bootloader | 0x08000000 | 18,472 | 131,072 | 8,344 |
| Cabinet_CM4_Gate | 0x08100000 | 1,524 | 131,072 | 8,192 |
| MIPIProject_CM7 | 0x08020000 | 528,720 | 917,504 | 252,064 |
| MIPIProject_CM4 | 0x08120000 | 32,928 | 917,504 | 92,992 |

BIN 长度包含地址间填充，与 Keil 的 Code + RO + RW 统计可能不同。RAM 统计包含静态 RTOS 堆/栈预留，不代表实测任务栈余量；另有 SDRAM 帧缓冲和 1 MiB LVGL 堆，未计入这个 RW/ZI 表。

已检查两核镜像信息分别位于 0x08020400 / 0x08120400，长度 32 字节；CM7 调试串口 DMA 缓冲位于 0x30040000，与 CM4 RAM 分区分开。Keil 四目标的启用源文件路径均存在，工程无需引用工作空间外的 GUI Guider 文件。

掉电测试使用模拟 NOR/内部 Flash，约束写入只能从 1 变 0、分区边界及启动扇区保护；它不模拟实际芯片 ECC、电压变化、时序和全部可能的中断字节位置。真实烧写掉电试验仍需执行。

测试日志位于 `build/host-tests.log`、`build/package-tests.log`、`build/ui-tests.log`。可复现命令：

```powershell
./tools/build.ps1 -Rebuild
./tools/test.ps1
python tests/test_tools.py
./tools/preview_ui.ps1 -Python python
```

主机 C 测试需要 GCC；UI 预览还需要 CMake、Ninja 和 Python Pillow。固件编译不依赖这些主机测试工具，字体 C 文件已包含在工程中。
