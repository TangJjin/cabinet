# 第三方组件与适配记录

| 组件 | 来源 | 当前用途/许可 |
|---|---|---|
| STM32 CMSIS / HAL | 原工程；补齐同版本 STM32CubeH7 V1.12.1 本地仓库缺少的源文件和头文件 | STM32H747 BSP；保留 `Drivers/STM32H7xx_HAL_Driver/LICENSE.txt` 及源文件声明 |
| FreeRTOS Kernel | 原工程 V11.3.0 | 两核任务调度；MIT，源文件保留许可 |
| LVGL | 原工程 9.3.0 | 手写界面、字体、图表；保留原许可 |
| OpenAMP / libmetal | 本机 STM32CubeH7 V1.12.1，参考 STM32H747I-EVAL/OpenAMP_PingPong | RPMsg/virtio；保留各文件 BSD-3-Clause 及 ST 适配声明 |
| FatFs | 提供板卡例程的 FatFs R0.14b | 单卷短文件名；保留 ff.c/ff.h 原许可 |
| 中文字形 | 已有 UI 素材 SourceHanSerifSC-Regular.otf，转换为 cabinet_font_24 | SIL Open Font License，完整许可 `tools/font/OFL.txt`；衍生字库使用新名称 |
| lv_font_conv | npm 1.5.3，锁定在 tools/font/package-lock.json | 生成 24 px 子集字体，普通固件构建不需要 Node/npm |

本项目对 vendor 代码的适配：libmetal 的 IRQ 保存/恢复、ARM Compiler 6.7 原子头选择、NULL 头文件、互斥量初始化括号；OpenAMP 的 clang 优化 pragma；FatFs diskio.h include 路径；LVGL UEFI 内存适配文件补齐条件编译结束符及一个数组初始化括号；HAL SD 的 ACMD41 上电协商增加 1.5 秒上限，避免异常卡反复应答“未就绪”导致存储任务长时间阻塞。其余新增业务位于 APP、Common、Bootloader、tools 和 tests。

保留原面板初始化数据 `APP/SYSTEM/bsp_system.c`、MIPI/LTDC/FMC 时序和触摸协议。仅清理 LVGL 输入示例中没有启用的鼠标/键盘/编码器模板，继续调用原 `Touch_Read()`。

复现字库可执行 `npm ci --prefix tools/font` 后使用 `tools/font/generate.ps1 -Font <SourceHanSerifSC-Regular.otf 路径>`；转换后的 C 文件已在工程内，无需安装系统字体。增加界面汉字后需重新生成子集。
