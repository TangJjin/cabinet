# 接线与资源分配

依据提供的 STM32H747XIH6 CB V1.1 原理图、用户手册与现有可运行屏幕工程。下面的新外设引脚按本项目选择；实际模块型号变化时，先核对接口电平和传感器寄存器表。

## 新增外设

| 模块信号 | STM32 引脚 | 外设/方向 | 所属核 |
|---|---|---|---|
| RS485 模块 DI | PG14 | USART6 TX AF7 | CM4 |
| RS485 模块 RO | PG9 | USART6 RX AF7 | CM4 |
| RS485 DE 与 /RE 并接 | PG12 | 高=发送，低=接收 | CM4 |
| 水浸逻辑输出 | PC13 | 内部上拉，低有效 | CM4 |
| 有源蜂鸣器模块 IN | PG13 | 高有效，需带驱动 | CM7 |


原理图第 6 页排针索引：PG14=P1-13，PG9=P1-7，PG12=P1-8，PC13=P2-6，PG13=P1-9。3.3 V 可从 P2-1 获取，GND 为 P2-2。接线前依据实板丝印确认 P1/P2 的 1 脚方向，不能按屏幕图片朝向直接推断。

RS485 选用 3.3 V 逻辑的 MAX3485/SP3485 模块，或者带隔离、支持 3.3 V 控制的工业模块；不要把 5 V RO 输出直接接 MCU。总线连接 A/B，端点根据实际布线配置终端与偏置，避免每块模块都叠加终端电阻。

温湿度参考协议选 **Seeed S-TH-01**，其文档定义温度寄存器 0（有符号 0.01 ℃）、湿度寄存器 1（无符号 0.01 %RH），9600、8N1，03/04 读取。本工程使用 03。默认地址选 1，文档还提到部分版本默认为 42；可在页面修改。传感器供电范围为 3.6～30 V，不能直接假设板上 3.3 V 足够，按实物规格独立供电。其他“通用 RS485 温湿度传感器”可能采用不同地址、顺序和倍率，不能直接混用。

水浸可以先用干接点/开漏输出模块；调试时用开关将 PC13 与 GND 短接模拟水浸，松开恢复。若传感器输出 12/24 V，先通过合适的隔离/电平转换模块。

蜂鸣器选带驱动、3.3 V 输入兼容的高电平触发有源模块。PG13 只提供逻辑控制，不直接供蜂鸣器负载电流。继电器不接入。

## 保留的板载资源

| 资源 | 使用范围/备注 |
|---|---|
| MIPI / LTDC / DMA2D | 保留原面板时序、初始化表、画面旋转与触摸坐标转换 |
| 显示控制 | PB0 背光、PH5 复位、PI11 电源使能 |
| 触摸 | I2C2 PB10/PB11、PB12 复位、PB5 中断引脚（现有驱动轮询读取） |
| SDRAM | FMC Bank2，0xD0000000，32 MiB，原 FMC 引脚全部保留 |
| QSPI W25Q256 | PF6/PF7 数据 AF9、PF8/PF9 数据 AF10、PF10 时钟 AF9、PG6 片选 AF10 |
| TF 卡 | SDMMC1：PC8/PC9/PC10/PC11 数据、PC12 时钟、PD2 命令 |
| SD NAND | SDMMC2，本项目未初始化或使用 |
| EEPROM | I2C4 PD12/PD13，本项目参数改存板载 QSPI，未占用这组引脚 |
| 串口调试 | USART1 PA9/PA10，115200、8N1，保留板载 USB 串口路径 |
| RGB 灯 | PA3 绿色通道、PB1 蓝色通道，低电平亮；红色通道固定接地常亮 |

新引脚没有与上述正在使用的资源重叠。未启用摄像头、SPI4 显示口等其他复用功能；以后扩展时应重新查冲突。

## 内存与中断

| 内存 | 分配 |
|---|---|
| AXI SRAM 0x24000000～0x2407FFFF | CM7 数据、栈、FreeRTOS 堆、LVGL 局部绘图缓冲 |
| D2 SRAM 0x30000000～0x3003FFFF | CM4 数据、栈、RTOS 堆、USART6 DMA 缓冲 |
| D2 SRAM3 0x30040000 起 | CM7 USART1 DMA 缓冲 128 字节，避免与 CM4 冲突 |
| SRAM4 0x38000000 起 | OpenAMP 资源表 |
| SRAM4 0x38000400 起 | vrings 和 RPMsg 缓冲区，共享范围 0xB000 字节 |
| SRAM4 0x3800FC00 | 启动门邮箱 |
| SDRAM 0xD0000000 起 | 原 RGB565 帧缓冲，1280×800×2 字节 |
| SDRAM 0xD0200000 起 | LVGL 1 MiB 内存池，与帧缓冲隔离 |

CM7 开启 I-Cache；本实现保持 D-Cache 关闭，并将 SDRAM、SRAM4 配为共享、不可缓存的普通内存。以后启用 D-Cache 必须重新处理 DMA/共享区 MPU 属性及 clean/invalidate，不能只加一句 EnableDCache。

HSEM 15 用于启动门，HSEM 0/1 用于 OpenAMP 消息通知。CM4 使用 DMA2 Stream0 接收 USART6；CM7 USART1 使用原 DMA1 Stream0。HSEM、串口和 DMA 中断优先级为 6，满足 FreeRTOS 从中断调用 API 的限制（阈值为 5，数值越小紧急程度越高）。

CM7 CPU 480 MHz，CM4/HCLK 240 MHz，APB 120 MHz。FreeRTOS 使用各核 `SystemCoreClock`，修正原 CM7 固定写 240 MHz 导致节拍不匹配的问题。PLL1Q 120 MHz，SPI1 分频后 15 MHz，SDMMC1 数据阶段 20 MHz，QSPI 30 MHz。
